# Машина

Предсказывает, какие пары научных областей свяжутся в ближайшие 6 лет, по данным OpenAlex до года среза. Сейчас это проверка на прошлом: срезы 1996–2012, проверка по 2018 году.

## Что уже известно (50 областей, 10–11.11.2026)

- Новые связи предсказуемы. AUC сходства окружения 0,72–0,87 после чистки меток.
- Почти половина «связей» по тегам OpenAlex — шум разметки. Слепой аудит 96 работ: 53 настоящих, 43 артефакта.
- Импакт новой связи не зависит от того, насколько она предсказуема: коэффициент −0,03, 95% интервал −0,32…0,25.
- Вывод «предсказуемое — это продолжение» снят: после фильтра доля продолжений 14–81%.
- На 50 областях узкое место — размер выборки. Поэтому следующий прогон идёт на 500 областях.

Подробности — во вкладке «Самопроверка 2» мастер-документа.

## Правила подсчёта

1. Работа засчитывается как общая, только если у неё оба тега и обе сущности названы в заголовке или аннотации (`mashina/synonyms.py`).
2. Пары «часть — целое» выбрасываются до модели.
3. Текст проверяется по скачанным работам: 1 кредит за 200 работ. Серверный поиск стоит 10 кредитов за запрос и в коде запрещён.
4. Области выбираются правилом, а не вручную. Это 50 базовых плюс 450 случайных из 25 683 понятий уровня 2–3 с 5 000+ работ, seed 42 (`mashina/areas.py`). Задумывалась выборка по разделам науки, но при выборе разделы не подгрузились, поэтому выборка вышла простой случайной. Это записано, а не скрыто.
5. Синонимы из Wikidata берутся только тогда, когда их нельзя спутать с обычным словом: несколько слов, дефис, цифра или аббревиатура. Например, «error» как синоним «Software bug» отброшен.

## Как работает

Каждую ночь в 01:40 по Копенгагену GitHub Actions запускает `python -m mashina nightly`. Прогон тратит не больше 9 500 кредитов OpenAlex из 10 000 и продолжает с места, где остановился. Данные сохраняются коммитом в `data/`, отчёты — в `reports/`.

Порядок:
1. Выбор областей.
2. Шаблоны синонимов.
3. Счётчики по парам. Пачка из 50 пар без общих работ стоит 1 кредит.
4. Чистка меток текстом.
5. Оценка.

Прогресс смотри в `reports/status.md`, итог — в `reports/results.md`.

## Промежуточный результат

Сбор идёт по областям по порядку. Как только для первых 120+ областей собраны все пары, машина один раз считает результат на этой полной подсети и пишет его в `reports/interim.md`. Ожидается утром 17.11.2026. Проверки по тексту, которые для этого нужны, входят в финальные, поэтому основной прогон ничего не теряет.

Критерий записан до результата, он тот же, что в «Самопроверке 2»:
- метод работает, если на чистых метках AUC лучшего метода не ниже 0,75 и верхние 20 пар связываются минимум в 3 раза чаще случайных;
- метод провален, если AUC ниже 0,65 или преимущество над признаком «рост» меньше 0,03;
- между порогами — продолжать и проверять на всех 500.

Это промежуточная проверка на части областей. Окончательный вывод делается только по `reports/results.md`.

## Ключ

Ключ OpenAlex хранится только в секрете репозитория `OPENALEX_KEY` (Settings → Secrets and variables → Actions). В код, URL и чат он не попадает.

## Проверка

`python -m pytest tests`. Тесты без сети воспроизводят прогон из браузера от 10.11.2026: AUC 0,851 / 0,793 / 0,749, обученная модель 0,917 / 0,851 / 0,802. Ещё один тест проверяет, что ночной сбор продолжается после остановки по бюджету.
